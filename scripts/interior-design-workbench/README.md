# AI 数字工作台 - 使用说明

> 适用于室内设计/装修行业，帮助建立手机 → 云端 → 电脑的自动化文件管理体系。

## 三个工具

| 文件 | 作用 | 依赖 |
|------|------|------|
| `01_setup_folders.bat` | 在 `D:\AI_System\` 创建完整目录结构 | 无（Windows 直接运行） |
| `02_rename_files.py` | 交互式批量重命名收件箱文件 | Python 3.8+ |
| `03_ai_classify.py` | AI 自动识别图片类型并归档 | Python + anthropic + 可选 pillow |

---

## 第一步：创建目录结构

1. 下载 `01_setup_folders.bat` 到你的电脑
2. **双击运行**（或右键 → 以管理员身份运行）
3. 脚本会自动在 `D:\AI_System\` 创建全套目录
4. 同时生成三个文档：
   - `02_装修案例库\案例索引.md` — 案例记录模板
   - `01_客户项目\客户档案.md` — 客户信息模板
   - `03_AI系统\文件命名规范.md` — 命名规则说明

> 如果你的系统没有 D 盘，打开 .bat 文件，把第 9 行的 `D:\AI_System` 改成你想要的路径。

---

## 第二步：安装 Python（用于工具 2 和 3）

1. 下载 Python：https://www.python.org/downloads/
2. 安装时勾选 **"Add Python to PATH"**
3. 打开命令提示符（cmd），验证安装：
   ```
   python --version
   ```

---

## 第三步：批量重命名文件

把需要整理的文件放入 `D:\AI_System\99_临时收件箱\待分类\`，然后：

```cmd
python 02_rename_files.py
```

程序会逐个显示文件，引导你输入：
- 日期（默认用文件修改日期）
- 客户名
- 文件类型
- 补充说明

重命名后文件仍在收件箱，需要手动或用工具 3 归档。

---

## 第四步：AI 图片自动分类

### 安装依赖

```cmd
pip install anthropic
pip install pillow  # 仅 HEIC 格式需要
```

### 设置 API Key

```cmd
set ANTHROPIC_API_KEY=sk-ant-你的密钥
```

> API Key 在 https://console.anthropic.com/keys 获取。费用很低，分类 100 张图片约 ¥0.1。

### 运行

```cmd
python 03_ai_classify.py
```

程序会：
1. 扫描收件箱中所有图片
2. 用 AI 识别每张图片的内容类型（效果图/户型图/施工现场/合同等）
3. 建议归档路径
4. **等你确认后**才移动文件

## 文件命名规范

```
[YYYYMMDD]_[客户名]_[文件类型]_[说明].扩展名
```

示例：
- `20240315_王先生_效果图_客厅.jpg`
- `20240401_李总_合同_已签.pdf`
- `20240510_Johnson_CAD图纸_v3.dwg`

---

## 手机同步设置（Android）

1. **FolderSync**（推荐）
   - 同步对：手机相机 → 云盘 `AI_System/99_临时收件箱/手机照片`
   - 同步对：微信文件夹 → 云盘 `AI_System/99_临时收件箱/微信文件`
   - 频率：每 4 小时，仅 WiFi

2. 微信文件夹路径（Android）：
   - `/storage/emulated/0/Android/data/com.tencent.mm/MicroMsg/`

---

## 安全提醒

**以下文件不要放入自动同步目录：**
- 银行卡照片
- 身份证
- 微信验证码截图
- 支付密码相关内容
- API Key 文件
